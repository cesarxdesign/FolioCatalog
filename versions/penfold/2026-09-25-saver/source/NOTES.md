# Penfold, Saver: the story as one saver's path through the product

Written 2026-09-25 from the same sources as Linear (see `../2026-09-25-linear/source/NOTES.md`).
Same system as Cable Noir; text only; light and dark.

## Spine

- **Week 1, before any saver** - the setting: 7 days to live, the funding round.
- **01 Finds us** - the flip to existing pension holders: 100 to 600 signups a month (the biggest
  win, first).
- **02 Signs up** - account first, five modules, mobile from one component set (half the
  engineering load, shipping daily).
- **03 Owns a pension** - five days of partner hand-offs to a pension on the spot.
- **04 Brings old pots** - Combine: bad versions still count, then doing it right, the employer
  field added on purpose.
- **05 Watches it land** - transaction history designed backwards, built up like Lego.
- **06 Asks the hard question** - Joe T.'s "What if I die?", and the feedback loop that put him
  in the room.
- **Closer** - 12 savers in week one, 3,000 and £4M by the end of year one; the £1B as the
  company's trajectory.

Why: each win sits where its context lives in the product, so no context strips are needed and
the biggest win still comes first. Combine and transaction history get their own stops.
